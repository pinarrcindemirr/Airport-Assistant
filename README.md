# VIA — Vion International Airport Passenger Assistant

## Installation

```bash
git clone <repo-url>
cd Airport-Assistant

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

## Running

```bash
streamlit run frontend/app.py
```
